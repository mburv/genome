# Whole human reference assembly

The 31-gene main campaign is unchanged. After all non-lab main puzzles are complete the player unlocks the entire T2T-CHM13v2.0+Y reference (GCA_009914755.4): autosomes, X, Y from HG002 and mitochondrial DNA. It is a composite reference, not one person's diploid genome. Every A/C/G/T coordinate is playable. The JHU RefSeq/Liftoff v5.3 annotation supplies complete gene spans including introns, noncoding genes and pseudogenes. The 31 Famous Genes use their CDSs extracted directly from the same T2T packed chromosomes using RefSeq/Liftoff v5.3 transcript annotations. Completing each main puzzle credits its exact genomic coordinates, including reverse-strand and exon-spanning intervals. The bonus map skips all credited bases. Legacy RefSeq completions retain historical achievement and exact matching coordinate credit; variant bases remain playable in the genome map. Intergenic sequence is accessible via chromosome assembly.

## Data and integrity

Run python3 scripts/prepare-genome.py. It downloads official T2T FASTA and JHU annotation, checks the published archive MD5, checks every chromosome length and every sequence base, and generates 25 portable 2-bit chromosome packs with locus annotation and SHA-256 per packed chunk. The full payload is about 780 MB and is not embedded in the app or repository. The data workflow uploads the packs as a downloadable artifact. Extract and select one or more .genome files in the bonus map. Files are read locally with bounded slices; IndexedDB retains packs offline when browser quota permits; otherwise the player reselects them after reopening. No network requests during play. Chunk hashes detect corrupt payloads; the pack header is trusted as generated by the verified pipeline. Progress is stored separately from reference packs, but both campaigns share the same coordinate ledger. No personal DNA files are supported.

## Progress

The canonical state is a union of half-open reference coordinates per chromosome. Completing a puzzle credits only previously unsolved bases. Overlapping genes count the same coordinate once, and a gene completes when its complete genomic span is covered. A chromosome is complete only when all bases are covered; the genome completes only when all 25 chromosomes are covered. Coordinate intervals are saved in the existing save schema as a separate optional field. No sampled-gene progress is converted to coordinate credit.

On-demand levels cover 9, 27, 54, then up to 864 bases (nine 96-base tiles), clipped to a remaining gap and gene boundary. The existing DNA tracing, mutation correction and genome assembly engines are reused; certificates are replayable and the win requires exact extracted reference sequence. No pre-generated millions of boards. Gene and chromosome views share the same progress. Bonus layouts reuse the existing mechanic templates, not the main sliding-board mask invariant. The main campaign's full range of mechanics and progression is unchanged.

Limitations: full reference data is a separately installed asset; unfinished bonus puzzles restart; browser storage quotas can require reselecting packs after a reload. At 864 bases per late puzzle there are more than 3.6 million puzzles at minimum; no completion shortcuts or automatic credit are provided. The reference is pinned, not every human variant.

The nuclear Liftoff annotation excludes mitochondria. `scripts/annotate-mito.py` maps the 37 rCRS gene features (NC_012920.1) to the actual CHM13 mitochondrial sequence (CP068254.1) using a verified global alignment after rotation. The publishing workflow validates all packed chromosome hashes and publishes individual packs as release assets. For a fresh local build, run the mitochondrial annotation script after `prepare-genome.py` (requires Biopython 1.86).

The build-time extraction script `scripts/extract-famous-t2t.py` selects the annotated RefSeq transcript for each Famous Gene, reads its coding intervals directly from the verified 2-bit chromosome packs, and records sequence SHA-256, transcript order and strand. `scripts/build-shared-campaign.ts` rebuilds the puzzles for reference variants while leaving the historical source assets intact for save migration and provenance. The T2T Famous Genes CDS total is 63,030 bases (GPX1 −6 and HTT +27 relative to the original campaign). Historical completion is preserved without false reference credit; missing or changed bases can be assembled in the bonus map. Optional enzyme labs award no coverage.

The final board refresh preserves all compatible original masks and solution certificates, including boards whose only change is a genuine decoy's source slice. It regenerated 47 of the 215 levels associated with altered genes (including one optional lab); 168 retained their original layouts. A fully completed pre-T2T Famous Genes save carries forward 62,969 exact reference bases, leaving 61 new/changed coding bases for the Human Genome map. The 413-level campaign covers 63,030 unique T2T bases without overlapping coordinates.
